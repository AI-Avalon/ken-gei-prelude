# Crescendo 使い方ガイド

このガイドは、演奏会の閲覧・登録・編集・共有・管理で使う画面をまとめたものです。

## 演奏会を見る

1. `/concerts` で演奏会一覧を開きます。
2. キーワード検索、カテゴリ、日付で絞り込みます。
3. 詳細ページで日時、会場、チラシ、料金、プログラム、出演者、アクセスを確認します。

## 演奏会を登録する

1. `/upload` を開きます。
2. タイトル、日付、開演時刻、会場、カテゴリを入力します。
3. 必要に応じて出演者、プログラム、料金、チラシを追加します。
4. 編集用パスワードを設定して登録します。

編集用パスワードは編集・削除に使います。忘れた場合は、管理者が管理画面から新しい編集用パスワードを再設定できます。

## 編集・削除する

1. 演奏会詳細ページの「編集する」を開きます。
2. 登録時の編集用パスワードで認証します。
3. 情報やチラシを更新します。
4. 削除すると、演奏会は論理削除され、管理画面の削除済みフィルターで確認できます。

認証に成功した編集用パスワードは、同じブラウザタブ内では `sessionStorage` に一時保存され、再入力を省略します。

## 共有する

詳細ページの共有欄から以下を使えます。

- URLコピー
- 端末の共有シート
- LINE / X / Facebook / Threads
- QRコード表示
- QRコード SVG 保存

`/concerts/:slug` は Cloudflare Pages Functions で個別の OGP メタタグを返します。SNS やチャットにページ URL を貼ると、演奏会タイトル、説明、チラシ画像のプレビューが表示されます。

## 管理する

1. `/admin` を開きます。
2. `ADMIN_PASSWORD` に設定した管理者パスワードでログインします。
3. 演奏会管理で公開・非公開、削除、編集用パスワード再設定を行います。
4. 自動取得データは「自動取得」フィルターで確認でき、一括削除できます。
5. チラシ管理でサムネイル有無や未登録データを確認します。
6. 設定画面で PDF 事前変換、スクレイピング、メンテナンス、バックアップを実行できます。

## パスワード

- 管理者パスワード: Cloudflare Pages の Secret `ADMIN_PASSWORD` に設定します。
- 編集用パスワード: 演奏会ごとに登録者が設定します。DB には SHA-256 ハッシュのみ保存します。
- パスワード再設定: 管理画面の演奏会管理から、新しい編集用パスワードを設定します。
