# Crescendo 使い方ガイド

Crescendo は、愛知県立芸術大学の演奏会を「探す・登録する・共有する・カレンダーに入れる」ための演奏会ポータルサイトです。

## 初めて見る人

1. `/concerts` で演奏会一覧を開きます。
2. キーワード、カテゴリ、日付で絞り込みます。
3. 詳細ページで日時、会場、チラシ、料金、出演者、地図を確認します。
4. 気になる演奏会は「カレンダーに追加」から予定表に入れます。

## 演奏会を登録する人

1. `/upload` を開きます。
2. タイトル、日付、開演時刻、会場、カテゴリを入力します。
3. 必要に応じて料金、出演者、プログラム、説明文、連絡先を追加します。
4. チラシ画像またはPDFを追加します。PDFはページごとに画像化され、表/裏も表示できます。
5. 編集用パスワードを設定して登録します。
6. 登録後の詳細ページURLをSNS、QR、LINE、メールなどで共有します。

編集用パスワードは編集・削除に使います。忘れた場合は、管理者が管理画面から新しい編集用パスワードを再設定できます。

## 付属ポスターを例にした入力

`チェロ_ポスター最終.pdf` から確実に読める基本情報だけを登録例に使います。

| 項目 | 入力値 |
|---|---|
| タイトル | Ensemble Celliberta 20th Anniversary Concert |
| 日付 | 2027-02-20 |
| 開場 | 17:30 |
| 開演 | 18:00 |
| 料金 | 入場料 ¥1,000 |
| カテゴリ | アンサンブル |
| 専攻 | 弦楽器 |

会場、出演者、チケット詳細など、ポスター画像から確実に読み取れない細部は推測せず、確認できてから追記します。

## 宣伝に使う

詳細ページを作ると、次の導線が使えます。

- URLコピー
- 端末共有
- LINE / X / Facebook / Threads / Bluesky / メール
- QRコード表示、URLコピー、SVG保存
- 個別OGPプレビュー
- Google / Apple / Outlook / TimeTree / Yahoo! / ICSカレンダー追加

宣伝画像と投稿文面は `docs/PROMOTION_KIT.md` にまとめています。画像は `public/promo/crescendo/` に保存しています。

## 管理する

1. `/admin` を開きます。
2. `ADMIN_PASSWORD` に設定した管理者パスワードでログインします。
3. 演奏会管理で公開・非公開、削除、編集用パスワード再設定を行います。
4. チラシ管理でサムネイル有無やPDF変換状況を確認します。
5. 設定画面でスクレイピング、メンテナンス、バックアップを実行できます。
