# Flyer & PDF Hybrid Renderer

## 監査・実装ルール
1. **ネイティブ `<iframe>` / `<embed>` / `<object>` 直読みの禁止**:
   - iOS Safari や Android Chrome で「変な枠だけが表示される」原因となるため、HTMLタグによるPDFの直接インライン埋め込みを全面禁止する。
2. **3段階ハイブリッド描画 (`FlyerPreview` コンポーネント)**:
   - **第1優先 (WebP高速表示)**: R2または事前変換された高画質WebP画像（表面・裏面）をアスペクト比 `1 / 1.414` (A4比率) の美しいコンテナ内に `object-contain` で描画する。Skeleton / Blurプレースホルダーを備え、読み込み中のレイアウトシフト（CLS）をゼロにする。
   - **第2優先 (PDF.js Canvas レンダリング)**: WebP画像が未生成でPDF URLのみ存在する場合、ブラウザ側の軽量 `pdfjs-dist` を用いて `<canvas>` 要素に1ページ目（表面）と2ページ目（裏面・存在する場合）を直接レンダリングする。これによりモバイルでも100%確実にチラシの中身を表示する。
   - **第3優先 (エレガント・フォールバック)**: PDF自体が未登録または取得エラーの場合、壊れた枠や壊れた画像アイコンを絶対に出さず、公演タイトル・日時・会場をあしらったクラシック音楽風のタイポグラフィ・ポスターカードを自動生成して表示する。
3. **インタラクション要件**:
   - 表面・裏面のワンタップ切り替えタブ、ピンチズーム対応のフルスクリーン拡大ライトボックス、および「📄 公式PDFを別タブで開く」「📥 PDFを保存」のアクションバーをPC・スマホ共通で提供する。
