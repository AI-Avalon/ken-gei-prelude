# /test-before-deploy

Antigravity IDE の Customizations → Workflows → **+ Workspace** で新規作成し、
ファイル名を `test-before-deploy` として以下を貼り付けてください。
保存先は `.agent/workflows/test-before-deploy.md`。作業完了時に `/test-before-deploy` と打つと呼び出せます。

---

このワークフローを実行するときは、以下を順番に行い、それぞれの結果を報告すること。

1. `npm run build` を実行し、ビルドエラーが無いことを確認する。
2. `npm run smoke:chromium` があれば実行する。
3. 変更した `functions/api/**` がある場合、ローカルで起動して該当エンドポイントに
   実際にリクエストを送り、レスポンスを確認する（本番D1・KVには触れない）。
4. ブラウザエージェントで、変更に関係するページを以下2パターンで開いて確認する：
   - PC想定ビューポート
   - スマホ想定ビューポート（375px前後）
5. DBマイグレーションを追加した場合は、ローカルD1（`--local`）に適用してエラーが無いか確認する。
   リモートには適用しない（ユーザーの明示的な承認があるまで）。
6. 上記1〜5の結果を箇条書きでまとめ、問題があれば直さずに報告する（勝手に「大丈夫だろう」で進めない）。
7. すべて問題なければ、変更内容・確認結果・次にユーザーがやるべきこと（PR作成/マージ/Secrets設定など）を
   まとめて報告する。
